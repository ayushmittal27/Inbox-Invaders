🚀 Inbox-Invaders
Turn email cleaning into a fast-paced space shooter! Inbox Invaders maps unread emails to enemy ships, letting you clear digital clutter while playing a game.
✨ Features
Space Shooter Gameplay: Zapping targets automatically triggers real-world Gmail actions in the background.
Controls & Actions:
Space / Click: Delete spam
A Key: Archive mail
S Key: Star VIP emails
E Key: EMP bomb newsletter waves
🛠️ Tech Stack
HTML5, CSS3, JavaScript
